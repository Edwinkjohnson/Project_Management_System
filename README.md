# Project Management System

A full-stack project management web application built using React to streamline team collaboration, task tracking, and project organization.  
The system provides role-based dashboards for Admins, Managers, and Team Members with features such as task boards, project management, team management, analytics, and real-time collaboration.

## 🚀 Features
- Role-based authentication and dashboards  
- Project and task management  
- Team and user management  
- Analytics and progress tracking  
- Calendar integration  
- Chat module  
- Clean UI with modern component architecture  

## 🛠️ Technologies Used
- React
- JavaScript
- Context API
- CSS
- Git & GitHub

## 🎯 Purpose
This project demonstrates practical implementation of modern frontend development concepts and scalable application architecture.
